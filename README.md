DevPath

A DevPath é uma plataforma desenvolvida para buscar cursos de programação e ferramentas relacionadas a área de desenvolvimento, feita para programadores iniciantes e estudantes que precisam de ajuda na hora de encontrar um caminho menos complicado em direção ao sucesso profissional.

Release 1.0

- Cadastro da conta (CRUD)
- Menu
- Buscar cursos
- Banco de dados

Release 1.1

- Filtrar cursos
- Interface de exibição de cursos

Release 1.2

- Interface de ver detalhes do curso
- Favoritar curso
- Visitar Site oficial do curso
